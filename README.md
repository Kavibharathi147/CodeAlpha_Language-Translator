# Language Translation Tool - CodeAlpha AI Internship

A simple web app to translate English text to Tamil, Hindi, Telugu, etc using Google Translate API.

## Features
- Translate to 8+ languages
- Copy translation button
- Simple and responsive UI

## How to Use
1. Open index.html in browser
2. Type English text
3. Select language and click Translate

## Tech Used
HTML, CSS, JavaScript, Google Translate API
